# Bài tập: Lập trình Hướng Đối Tượng với C#

## Mô tả
Đây là chương trình mô phỏng quản lý nhân sự và nhóm dự án bằng ngôn ngữ C#. Chương trình áp dụng đầy đủ các kỹ thuật OOP được học:
- **Tính đóng gói (Encapsulation):** Bảo vệ dữ liệu bằng các Properties `get`/`set`.
- **Nạp chồng (Overloading):** Đa dạng hóa hàm khởi tạo và phương thức tính lương.
- **Tính đa hình (Polymorphism):** Sử dụng `virtual`/`override` để tính chi phí và hiển thị thông tin nhân sự.
- **Kết tập (Aggregation):** Quản lý danh sách thành viên trong nhóm dự án độc lập với vòng đời của nhân viên.

## Cách chạy chương trình
1. Mở thư mục dự án bằng VS Code.
2. Mở Terminal và chạy lệnh `dotnet run`.
3. Làm theo menu trên màn hình Console để test các kịch bản.
